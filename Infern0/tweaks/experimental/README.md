# Infern0 experimental tweaks

Experimental tweak sources for [Infern0](https://github.com/Nnnnnnn274/Infern0/).
These files are tracked directly in the public Infern0 repository under
`Infern0/tweaks/experimental/`.

They are open source under AGPL-3.0, matching the main Infern0 project. Beta
entries are free and visible in the app without account linking. In-development
entries can remain visible for continuity, but installation should stay disabled
until someone finishes and verifies them.

See `LICENSE`.
